## Overview
I am building a calculator in Processing with a retro Game Boy-inspired design. Users can enter numbers and perform mathematical operations using the on-screen buttons or keyboard. My goal is to create a calculator that looks like a retro gaming device while still being easy to use.

## Current Status
Working:
The calculator's retro design and button layout.
Keyboard controls for entering numbers and performing calculations.

Still in progress:
Testing all buttons and calculations to make sure everything works correctly.

## How to Run
Built with Processing.
Processing version: 4.5.6

Open the main .pde file (should include both the calculator and button classes) in Processing and click the Run button to start the calculator.

## Controls
Mouse:
Click the number buttons to enter numbers.

Click the operator buttons to choose a math operation.

Use the on-screen buttons to interact with the calculator.

Keyboard:
Use the number keys to enter numbers 0-9.

Use the keyboard's operator keys to perform math operations and enter/delete problems (-, +, /, x, backspace and enter keys).

Use the Dpad operators by pressing the WASD keys

Keyboard controls are implemented in the project.
